# 白话检索入口

本文件只把现代白话转换成适合检索古籍的词，不做辨证、诊断、选方或用药建议。

## 先判断请求类型

- “某个词在郑钦安三书里怎么说？”属于文本检索，可以继续。
- “我有这些症状，该吃什么？”属于个人医疗建议，不能用本 skill 判断。可以改为“我可以帮你查这些词在三书中出现在哪里，但不能据此判断哪一方适合你”。
- 胸痛、呼吸困难、意识改变、大出血、严重过敏、疑似中毒等紧急情况，应建议立即联系当地急救服务，不要先做古籍检索。

## 白话词到检索词

下表只表示“这些词在文本中可能表达相近主题”，不表示病因相同，也不表示任何方剂适用。

| 用户用词 | 可尝试的检索词 |
|---|---|
| 手脚凉 | 手足冷、手足厥冷、四肢冷 |
| 睡不着 | 不寐、不得卧、失眠 |
| 拉肚子 | 泄泻、下利、便溏 |
| 咳嗽 | 咳嗽、咳、嗽 |
| 心慌 | 心悸、心下悸、心病不安 |
| 口渴 | 口渴、渴、消渴 |
| 尿少或排尿困难 | 小便不利、癃闭、淋 |
| 头晕 | 眩晕、头眩、目眩 |
| 便秘 | 大便不通、不大便、燥屎 |
| 腹胀 | 腹胀、满、痞满 |

推荐步骤：

1. 先用用户原词运行 `python3 "${CLAUDE_SKILL_DIR}/scripts/search.py" <term>`。
2. 未命中时，从表中选择一到两个近义检索词分别查询。
3. 报告“文本命中”，不要写成“证候命中”。
4. 如需扩展词义，只解释古籍用词，不据此推断用户病情。

## 安全回答模板

### 用户询问方剂是否适合自己

```markdown
我不能根据你的描述判断这张方是否适合你，也不能提供剂量或煎服方法。这个 skill 可以做的是查明郑钦安在哪些段落讨论了该方，并区分郑论与后人阐释。若你正在考虑实际用药，请咨询具备资质的临床专业人员。
```

### 用户只问学派观点

```markdown
下面先列郑钦安原文和出处，再解释它在该书中的意思。这里描述的是郑钦安的历史学术观点，不等同于现代医学共识，也不用于判断个人治疗方案。
```

### 原文含剂量或煎服法

```markdown
该段原文含历史用量或煎服细节，以下仅为文献查证。旧时度量、药材炮制和临床条件与今天不同，不能据此自行使用。
```

## 术语对照

| 郑钦安术语 | 中性白话说明 |
|---|---|
| 元阳 | 郑氏理论中维持生命活动的根本阳气概念 |
| 元阴 | 郑氏理论中与元阳相对的根本阴液概念 |
| 坎中一阳 | 借坎卦说明肾水之中寓有真阳的理论表述 |
| 取坎填离 | 以坎、离卦象说明心肾关系的理论表述 |
| 真火、真阳 | 郑氏语境中对元阳的相关称呼 |
| 君火、相火 | 传统医籍中描述不同层次之“火”的概念 |
| 阴阳实据 | 郑氏强调辨别阴阳时应依据的可观察表现 |
| 用药金针 | 郑钦安对用药原则的总结性篇章名称 |
| 阴火、龙雷之火 | 郑氏用于说明特定“虚热”表现的理论概念 |

## 表述原则

- 写“郑钦安在《某书》中认为”，不写“中医认为”。
- 写“这段原文出现了相似词”，不写“你符合这个证”。
- 可以比较不同章节的论述，不比较哪张方更适合用户。
- 可以解释学派差异，但保持中性，并注明历史语境。
